Задача 1

а) В JSON попадут только Name и Score, так как это публичные свойства, а JsonSerializer по умолчанию работает только с ними. Поле secretCode не попадёт из-за модификатора private, а IsAlive — потому что это обычное поле, а не свойство.

б) Чтобы secretCode попал в JSON, но остался private, нужно повесить на него атрибут [JsonInclude]:
[JsonInclude]
private int secretCode = 42;

в) Два способа включить поле IsAlive:
1. Добавить над полем атрибут [JsonInclude] или переделать его в свойство public bool IsAlive { get; set; }.
2. Включить поддержку полей через настройки сериализатора:
var options = new JsonSerializerOptions { IncludeFields = true };
string json = JsonSerializer.Serialize(p, options);

Задача 3

1. File (File.ReadAllText) — файл совсем маленький, проще прочитать его целиком за один вызов без создания потока.
2. File (File.WriteAllText) — данных при автосохранении немного и файл перезаписывается целиком, поэтому хватит обычного класса File.
3. FileStream (в связке со StreamWriter в режиме дозаписи) — файл может вырасти до нескольких гигабайт, загружать его в память целиком нельзя, а поток позволяет дописывать строки в конец.
4. File (File.Exists и File.ReadAllText) — в классе File уже есть готовые методы для проверки существования файла и чтения его в строку.
5. FileStream — только поток умеет перемещаться по файлу на нужную позицию через Seek и перезаписывать конкретные байты, не трогая остальной файл.
